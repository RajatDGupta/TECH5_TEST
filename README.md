# TECH5_TEST - Movie & TV Show App

A modern Android application built with Jetpack Compose that leverages the TMDB API to display movies, TV shows, and people.

## 🚀 Features

- **Movies**: Browse popular, top-rated, and upcoming movies. View detailed information, including cast and trailers.
- **TV Shows**: Explore trending and popular TV series with detailed season and episode information.
- **People**: Discover popular actors and view their filmography and biography.
- **Search**: Powerful search functionality to find your favorite movies, TV shows, and actors.
- **Theme Support**: Full support for both **Light** and **Dark** modes.
- **Modern Tech Stack**: 
  - Jetpack Compose for UI.
  - Hilt for Dependency Injection.
  - Retrofit & Kotlin Serialization for Networking.
  - Paging 3 for efficient data loading.
  - Coroutines & Flow for asynchronous programming.

## 🔑 Setup & API Token

To run this app, you need an API Access Token from [The Movie Database (TMDB)](https://www.themoviedb.org/documentation/api).

1. Create a file named `secrets.properties` in the root directory of the project.
2. Add your TMDB Access Token to the file:

```properties
TMDB_ACCESS_TOKEN="your_tmdb_read_access_token_here"
```

*Note: Make sure to use the "API Read Access Token" (the long JWT one).*
